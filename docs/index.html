No Generation

Deciding without producing a single token.

A language model answering a multiple-choice question normally writes the answer — one token at a time, each pass depending on the last. Hundreds of forward passes to emit a word that was already decided at the first one.

It does not have to. The choice is visible in the logits of a single forward pass. Read it there and three things change: it gets faster, the output cannot be malformed, and you can see how close the call was.

A fruit fly's nervous system already works this way. Light hits the eye, current spreads through real wiring, descending neurons fire more on one side than the other. One pass. No tokens. And you can watch the whole thing happen.
